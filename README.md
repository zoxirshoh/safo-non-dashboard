# Safo Non: Bakery Management Dashboard

An admin dashboard for managing a bakery business: bread types, bakers, warehouse stock, shops, suppliers and expenses.

**Live demo:** https://safo-non.vercel.app

## Features

- **Dashboard** with key statistics
- **Bread types** (Non turlari): manage products
- **Bakers** (Novvoylar) and **managers**
- **Warehouse** (Omborxona): stock and warehouse reports
- **Shops** (Do'konlar) and **suppliers** (Yetkazuvchilar)
- **Expenses** (Chiqimlar)
- Login page, sidebar navigation, notifications and settings

## Tech stack

- Vue 3 (`<script setup>`)
- Vue Router
- Axios
- Vite, deployed on Vercel

## Getting started

```bash
git clone https://github.com/zoxirshoh/Safo-non.git
cd Safo-non
npm install
npm run dev
```
